## 1. 画面一覧

| 画面 ID | 画面名 | 内容 |
| --- | --- | --- |
| G-1 | ログイン画面 | アプリ名と「Google でログイン」ボタンを表示 |
| G-2 | ボード画面 | リストとカードを表示。すべての操作をここで行う |
| G-3 | カード詳細ダイアログ | カードのタイトル・説明・期限日を編集する（第 2 版） |
| G-4 | 確認ダイアログ | 削除・インポート・復元の前に表示する |
| G-5 | 自動バックアップ一覧ダイアログ | 自動バックアップを選んで復元する（第 2 版） |

## 2. 画面遷移

```
G-1 ログイン画面 ──ログイン成功──▶ G-2 ボード画面
       ▲                           │
       └──────ログアウト──────────┤
                                   ├─カードをクリック──▶ G-3 カード詳細ダイアログ
                                   ├─削除・インポート──▶ G-4 確認ダイアログ
                                   └─自動バックアップ──▶ G-5 自動バックアップ一覧
```

ログイン済みの状態で URL を開いた場合は、G-1 を飛ばして G-2 を表示する。

│ └─────────────┘ │                 │                 │              │

| 部品 | 内容 |
| --- | --- |
| ヘッダー | 左にアプリ名、右に Google アカウントの表示名と操作ボタン |
| お知らせ欄 | バックアップの案内（K-8）や通信切れ（D-4）のときだけ表示 |
| リスト | 幅 272px 固定。カードが入りきらない場合はリストの中を縦にスクロール |
| ボード | リストが画面の横幅に入りきらない場合はボードを横にスクロール |
| 「…」 | リストのメニュー（名前変更・削除）。第 2 版 |
| 「×」 | カードの削除ボタン。カードの右上に表示 |
| 「＋リストを追加」 | 第 2 版 |
| 「自動バックアップ」 | 第 2 版（K-12） |

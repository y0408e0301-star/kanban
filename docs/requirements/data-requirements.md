本書は要件定義書の一部である。承認は[要件定義書](requirements.md)で一括して行い、変更は要件定義書 16 章の手続きで行う。

本書では、利用者から見てアプリがどんなデータを扱うかを定める。

---

## 1. リスト

| 項目 | 型 | 必須 | 条件 |
| --- | --- | --- | --- |
| ID | 文字列 | ○ | アプリが自動で付ける。重複しない |
| 名前 | 文字列 | ○ | トリム後 1〜20 文字 |
| 並び順 | 数値 | ○ | 左から 0, 1, 2 … |
| 作成日時 | 日時 | ○ | 自動で記録 |
| 更新日時 | 日時 | ○ | 自動で記録 |

## 2. カード

| 項目 | 型 | 必須 | 条件 |
| --- | --- | --- | --- |
| ID | 文字列 | ○ | アプリが自動で付ける。重複しない |
| 所属リスト ID | 文字列 | ○ | 存在するリストの ID |
| タイトル | 文字列 | ○ | トリム後 1〜100 文字 |
| 説明 | 文字列 | | 0〜1,000 文字（第 2 版） |
| 期限日 | 日付 | | 年月日のみ（第 2 版） |
| 並び順 | 数値 | ○ | 上から 0, 1, 2 … |
| 作成日時 | 日時 | ○ | 自動で記録 |
| 更新日時 | 日時 | ○ | 自動で記録 |

## 3. 上限

| 対象 | 上限 |
| --- | --- |
| リストの数 | 10 個（最低 1 個） |
| 1 リストのカード | 100 枚 |
| ボード全体のカード | 500 枚 |
| 許可するアカウント | 5 件 |
| 自動バックアップ | 7 回分 |

## 4. 詳細

データの詳しい構造（ER 図）は[データ設計書](../design/data-design.md)で定める。

## 5. 保存する個人情報

Google アカウントのメールアドレスと表示名のみを保存する。表示名はヘッダーに表示するために使う。

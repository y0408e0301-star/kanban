## 1. 本書について

利用者がアプリでできること（機能要件）と、画面に表示するメッセージを定める。

- 見出しに「（第 1 版）」「（第 2 版）」と書いたものは、その版で作る。版ごとの範囲は要件定義書 2.1 のとおり
- 画面 ID（G-1 など）は[画面一覧](screens.md)を、データの項目は[データ要件定義書](data-requirements.md)を参照する
- 用語（トリム、文字数など）は要件定義書 5 章のとおり

## 2. 機能要件

### 2.1 ログイン・ログアウト（第 1 版）

| ID | 内容 |
| --- | --- |
| A-1 | ログイン画面で「Google でログイン」を押すと、Google のログイン画面が別ウィンドウで開く |
| A-2 | 許可リストに登録されたアカウントでログインすると、ボード画面を表示する |
| A-3 | 許可リストにないアカウントでログインした場合は、ログアウトさせたうえで、ログイン画面に「このアカウントでは利用できません。」と表示する |
| A-4 | 一度ログインすると、ログアウトするまでは、ブラウザを閉じて開き直してもログインしたままになる |
| A-5 | ヘッダーの「ログアウト」を押すと、確認なしでログアウトし、ログイン画面に戻る |
| A-6 | ブラウザの Cookie・キャッシュを削除した場合は、再度ログインが必要になる。データは消えない（D-2） |

### 2.2 ボード表示（第 1 版）

| ID | 内容 |
| --- | --- |
| B-1 | 初めてログインした利用者には、左から「未着手」「作業中」「完了」の 3 つのリストを作り、カードは 0 枚とする |
| B-2 | 2 回目以降は、前回までに保存された状態のリストとカードを表示する |
| B-3 | データを読み込んでいる間は、ボードの中央に「読み込み中…」と表示する |
| B-4 | 各リストの名前の右に、そのリストのカードの枚数を表示する（例：「未着手 (3)」） |
| B-5 | 画面の文字の大きさは 14px 以上とする |

### 2.3 リスト（第 2 版）

| ID | 内容 |
| --- | --- |
| L-1 | ボードの右端の「＋リストを追加」を押すと、リスト名の入力欄と「追加」ボタンが表示される |
| L-2 | リスト名を入力して「追加」または Enter キーで、ボードの右端にリストを追加する |
| L-3 | リスト名はトリムした後で 1〜20 文字とする。21 文字目以降は入力できない |
| L-4 | トリムした後のリスト名が 0 文字のときは追加せず、入力欄の下に「リスト名を入力してください。」と表示する |
| L-5 | リストは 10 個まで作れる。10 個あるときは「＋リストを追加」を表示しない |
| L-6 | 「…」メニューの「名前を変更」で、リスト名が入力欄に変わる。Enter キーまたは入力欄の外をクリックで保存、Esc キーで取り消す。名前の条件は L-3 と同じで、0 文字のときは変更前の名前に戻す |
| L-7 | 同じ名前のリストを作ってもよい |
| L-8 | 「…」メニューの「削除」で、確認ダイアログに「リスト「（リスト名）」と、中のカード（枚数）枚を削除しますか？」と表示する。「削除」でリストと中のカードをすべて削除し、「キャンセル」で何もしない |
| L-9 | リストが 1 つしかないときは、「…」メニューの「削除」を押せない状態（灰色）にする |

### 2.4 カード

#### 第 1 版

| ID | 内容 |
| --- | --- |
| C-1 | 各リストの下の入力欄にタイトルを入力し、「追加」ボタンまたは Enter キーで、そのリストの一番下にカードを追加する |
| C-2 | 追加した後は入力欄を空にし、入力欄にカーソルを残す（続けて入力できる） |
| C-3 | タイトルはトリムした後で 1〜100 文字とする。101 文字目以降は入力できない |
| C-4 | トリムした後のタイトルが 0 文字のときは追加せず、入力欄の下に赤字で「タイトルを入力してください。」と表示する。次に文字を入力した時点でこの表示を消す |
| C-5 | 1 つのリストのカードは 100 枚まで、ボード全体では 500 枚までとする。上限に達したときは追加せず、「カードは 1 つのリストに 100 枚（全体で 500 枚）までです。」と表示する |
| C-6 | カードの右上の「×」を押すと、確認ダイアログに「カード「（タイトル）」を削除しますか？」と表示する。「削除」で削除し、「キャンセル」または Esc キーで何もしない |
| C-7 | カードをマウスでつかんで別のリストの上で離すと、そのリストの一番下へ移動する |
| C-8 | ドラッグ中は、離すと入る先のリストの背景色を変えて示す |
| C-9 | リストの外で離した場合は、元の位置に戻す |

#### 第 2 版

| ID | 内容 |
| --- | --- |
| C-10 | 同じリストの中でカードをドラッグし、ほかのカードの間で離すと、その位置へ並べ替える |
| C-11 | 別のリストへ移動するときも、カードの間で離すとその位置へ入れる（C-7 は第 2 版でこの動きに置き換える） |
| C-12 | カードをクリックすると、カード詳細ダイアログ（G-3）を開く |
| C-13 | カード詳細ダイアログでは、タイトル・説明・期限日を変更できる。「保存」で反映し、「キャンセル」・Esc キー・ダイアログの外側のクリックでは反映せずに閉じる |
| C-14 | タイトルの条件は C-3・C-4 と同じ |
| C-15 | 説明は 0〜1,000 文字とし、改行を入れられる。1,001 文字目以降は入力できない |
| C-16 | 期限日は年月日のみ（時刻なし）とし、カレンダーから選ぶ。空（期限なし）にもできる |
| C-17 | 期限日があるカードは、タイトルの下に「2026/10/15」の形式で表示する。パソコンの日付で今日が期限の場合は橙色の文字で「今日まで」を、期限を過ぎた場合は赤色の文字で「期限切れ」を日付の横に表示する |
| C-18 | 説明が入っているカードには、タイトルの下に説明ありを示す記号「≡」を表示する |

### 2.5 データの保存・同期（第 1 版）

| ID | 内容 |
| --- | --- |
| D-1 | 追加・削除・移動・変更をしたら、保存ボタンなどを押さなくても自動でサーバーに保存する |
| D-2 | サーバーに保存したデータは、次の場合も消えない：ブラウザを閉じる、ブラウザの履歴・キャッシュ・Cookie を削除する、別のブラウザで開く、別のパソコンで開く、パソコンを買い替える |
| D-3 | 同じ利用者が複数のパソコン・ブラウザでボードを開いている場合、ある画面での変更を、ほかの画面にも 5 秒以内に反映する（再読み込みは不要） |
| D-4 | インターネットに接続できないときは、お知らせ欄に「インターネットに接続されていません。接続が戻るまで編集できません。」と表示し、ログアウト以外のすべての操作（追加・削除・移動・変更・エクスポート・インポート・自動バックアップの表示と復元）をできなくする |
| D-5 | 接続が戻ったら D-4 の表示を消し、5 秒以内にサーバーの最新の状態を表示して、操作できる状態に戻す |
| D-6 | サーバーへの保存に失敗した場合は、「保存に失敗しました。時間をおいてもう一度お試しください。」と表示し、画面をその操作の前の状態に戻す |
| D-7 | 2 つの画面で同じカードをほぼ同時に変更した場合は、後からサーバーに届いた変更を有効とする |
| D-8 | 操作しようとしたカード・リストが、ほかの画面ですでに削除されていた場合は、その操作を行わずに「ほかの画面で削除されたため、操作できませんでした。」と表示し、最新の状態を表示する。カード詳細ダイアログで編集中のカードが削除された場合も、ダイアログを閉じて同じ表示をする |

### 2.6 バックアップ・復元

#### 第 1 版（手動バックアップ）

| ID | 内容 |
| --- | --- |
| K-1 | ヘッダーの「エクスポート」を押すと、すべてのリストとカードを 1 つのファイルにして、パソコンにダウンロードする |
| K-2 | ファイル名は「kanban-backup-年月日-時分.json」とする（例：kanban-backup-20261003-1530.json） |
| K-3 | ファイルの形式は JSON とし、項目は[データ要件定義書](data-requirements.md)のとおりとする。ファイルにはファイル形式の版数（1）とエクスポートした日時を含める |
| K-4 | ヘッダーの「インポート」を押すと、ファイルを選ぶ画面を開く。選べるのは拡張子 .json のファイルのみとする |
| K-5 | ファイルを選ぶと、確認ダイアログに「現在のリストとカードはすべて削除され、ファイルの内容（エクスポート日時：○○、リスト ○ 個、カード ○ 枚）に置き換わります。よろしいですか？」と表示する |
| K-6 | 「置き換える」でデータを置き換え、「インポートが完了しました。」と表示する。「キャンセル」では何もしない |
| K-7 | 次のファイルは読み込まず、「このファイルは読み込めません。エクスポートしたファイルを選んでください。」と表示し、データは変更しない：JSON として読めない、必要な項目がない、文字数・件数が上限を超えている、ファイルが 3MB を超える（上限いっぱいのデータのファイルは約 1.7MB） |
| K-8 | 最後にエクスポートした日から 7 日以上たっている（一度もエクスポートしていない場合を含む）ときは、ボード表示時にお知らせ欄に「最後のバックアップから 7 日以上たっています。」と「エクスポート」ボタンを表示する。最後にエクスポートした日時はサーバーに保存する |
| K-9 | K-8 の表示は、エクスポートするまで毎回表示する |

#### 第 2 版（自動バックアップ）

| ID | 内容 |
| --- | --- |
| K-10 | その日（パソコンの日付）初めてボードを表示したときに、その時点のリストとカードの控えをサーバーに自動で保存する |
| K-11 | 自動バックアップは新しいものから 7 回分を残し、それより古いものは自動で削除する |
| K-12 | ヘッダーの「自動バックアップ」を押すと、自動バックアップ一覧ダイアログ（G-5）に、日時・リストの数・カードの枚数を新しい順に表示する |
| K-13 | 一覧から 1 つ選んで「復元」を押すと、K-5 と同じ内容の確認ダイアログを表示し、「置き換える」でその時点の状態に戻す |
| K-14 | 自動バックアップはアカウントの中に保存するため、ほかの利用者からは見えない |

## 3. メッセージ一覧

| No | 表示する場面 | メッセージ |
| --- | --- | --- |
| M-1 | 許可されていないアカウント | このアカウントでは利用できません。 |
| M-2 | ログインに失敗・中断 | ログインできませんでした。もう一度お試しください。 |
| M-3 | タイトルが空 | タイトルを入力してください。 |
| M-4 | リスト名が空 | リスト名を入力してください。 |
| M-5 | カードの上限 | カードは 1 つのリストに 100 枚（全体で 500 枚）までです。 |
| M-6 | カード削除の確認 | カード「（タイトル）」を削除しますか？ |
| M-7 | リスト削除の確認 | リスト「（リスト名）」と、中のカード（枚数）枚を削除しますか？ |
| M-8 | 通信切れ | インターネットに接続されていません。接続が戻るまで編集できません。 |
| M-9 | 保存失敗 | 保存に失敗しました。時間をおいてもう一度お試しください。 |
| M-10 | インポート・復元の確認 | 現在のリストとカードはすべて削除され、ファイルの内容（エクスポート日時：○○、リスト ○ 個、カード ○ 枚）に置き換わります。よろしいですか？ |
| M-11 | インポート完了 | インポートが完了しました。 |
| M-12 | 読み込めないファイル | このファイルは読み込めません。エクスポートしたファイルを選んでください。 |
| M-13 | バックアップの案内 | 最後のバックアップから 7 日以上たっています。 |
| M-14 | 操作対象がほかの画面で削除済み | ほかの画面で削除されたため、操作できませんでした。 |

M-2・M-3・M-4 以外のメッセージは、利用者が閉じるか次の操作をするまで表示する。
